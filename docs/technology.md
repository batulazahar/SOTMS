# Specialized Technology
Natural Language Processing(NLP)
## Concept
Natural Language Processing is a subfield of AI that allows computers to understand, interpret, and produce human language in both text and speech formats. It focused on quickly developed, becoming essential to many applications and particularly efficient in interaction between machine and human. Key concepts in NLP include text preprocessing, feature extraction, and text summarization. At a basic level, NLP works by receiving a transcript or text, processing its linguistic features, comparing these features with learned language patterns, and producing an output by generated summary of a tutoring session

## Frameworks, models, methods and tools
•	Automatic Speech Recognition (ASR)
ASR is a technology that converts spoken language into text. It can be used in the project to transcribe the recorded audio of a tutoring session into text, providing the raw data needed before any summarization can occur (IEEE Xplore, 2025).
•	Tokenizer 
Tokenizer is the process of braking text into smaller units called tokens, which helps machines process and analyse effectively. It helps to convert unstructured text into structured format (GeeksforGeeks, 2026). Also, it is easier to be used for doing tasks in classification or translation more accurate and efficient.
•	Hugging Face Transformers
Hugging Face is an open-source nature containing pre-trained models for NLP tasks. It enables performing tasks like sentiment analysis, text classification, translation and Q&A directly (Jamesty, 2026). Hence, it suitable for summarization and text generation and can be used in the project to easily implement the AI algorithms.
