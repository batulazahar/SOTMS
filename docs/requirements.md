# Requirements

## Functional requirements (what the system must DO)

1. The system shall allow students and tutors to register for an account and allow students, tutors, and administrators to log in securely.
2. The system shall allow students to browse available tutors, view tutor details, and select available time slots for tutoring sessions.
3. The system shall allow students to book tutoring sessions, make payments, and receive booking confirmation with a QR code.
4. The system shall send notifications and reminders to users about their upcoming tutoring sessions.
5. The system shall generate AI-based personalized learning summaries and interactive quizzes based on completed tutoring sessions.

## Non-functional requirements (how the system must PERFORM)

1. The system shall display requested pages and tutor information within **3 seconds** under normal operating conditions.
2. The system shall protect user accounts and personal information through secure authentication and appropriate access controls.
3. The system shall achieve at least **99% monthly availability**, excluding scheduled maintenance.
